# Anicap Frontend

This folder contains [Anicap](https://github.com/dcdaz/anicap) frontend

## Project setup
```
pnpm install
```

### Compiles and hot-reloads for development
```
pnpm run serve
```

### Compiles and minifies for production
```
pnpm run build
```

### Lints and fixes files
```
pnpm run lint
```
